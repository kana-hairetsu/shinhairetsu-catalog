# 新配列カタログ

日本語入力の配列を、ジャンル別に一覧できるサイトです。掲載内容のうちQ1〜Q4は、
各配列の作者ご本人（または了承を得た代理の方）による自己申告をそのまま載せています。
主催側による評価や順位づけは行っていません。

Astro で作った静的サイトです。ビルドすると HTML だけが出力されるので、
Cloudflare Pages にそのまま載ります。

---

## はじめて動かすとき

Node.js が必要です。[nodejs.org](https://nodejs.org/) から LTS 版を入れてください。

```
npm install       # 最初の1回だけ
npm run dev       # http://localhost:4321 で確認できる
```

`npm run dev` を動かしたままファイルを編集すると、ブラウザが自動で更新されます。
確認が終わったら Ctrl+C で止めます。

```
npm run build     # dist/ に本番用の HTML を出力する
npm run preview   # build した結果を確認する
```

## 配列を1つ増やす手順

### 1. CSV に1行足す

`src/data/layouts.csv` を開いて、いちばん下に1行足します。
**掲載順は書いた順ではありません。** ジャンル別・五十音順に自動で並び替わるので、
どこに書いても正しい位置に入ります。掲載数の表示も自動で数えます。

| 列 | 中身 |
|---|---|
| `id` | URL になる文字列。半角英小文字とハイフンのみ。**一度公開したら変えない** |
| `name` `kana` | 配列名と読み仮名。`kana` が並び順の基準になる |
| `genre` | `romaji` / `gyodan` / `kana` / `kanchoku` / `sokki` |
| `author` `year` `version` `url` | 基本情報 |
| `resources` | 練習用教材。`名称^URL` を `;` で区切って複数書ける |
| `proxy` | **代理入力者のお名前。作者ご本人が回答された場合は空欄**。ここに名前が入っていると、各設問の出典表記と末尾の注記が代理入力用の文面に切り替わる |
| `consent` | 作者ご本人の了承。`あり` / `なし` / `連絡がつかないため未確認`。記録用で、ページには表示されない |
| `chord` `shift` | 同時打鍵の有無、シフト方式 |
| `os` `software` `phys_keys` `thumb` `keyboard` | 動作環境 |
| `geometry` | `row`（ロウスタッガード）／ `ortho`（オーソリニア）／ `column`（カラムスタッガード）。**配列図・ヒートマップ・動画の3つすべてがこの指定に従う** |
| `keymap` | 配列図をデータから描く場合の印字。下記参照 |
| `keymap_sub` | 裏レイヤー（シフト同時押し）の印字。同上 |
| `figure` | 作者提出の配列図。`public/figures/` に置いたファイル名 |
| `anim` | タイピング動画のデータ名。`public/anim/<名前>.json` に対応 |
| `q11` `q12` `q13` | Q1。`q13` は 0=速度を意識 / 1=両立 / 2=快適さ重視 |
| `q21` `q21c` `q22` `q23` | Q2。`q21` は 0=短め / 1=普通 / 2=長め |
| `q31` `q32` | Q3。`q31` は一覧カードにも出る |
| `q4` | Q4。空欄なら「ご回答はありません」と表示される |
| `updated` | 最終更新日 |

**CSV は Excel で開かないでください。** 文字化けや書式の自動変換が起きます。
メモ帳、VS Code、または GitHub の画面上で直接編集してください。

### 2. 配列図を用意する

2通りあり、どちらか一方があれば表示されます。両方あるときは `keymap` が優先されます。

**データから描く場合**は `keymap` に段ごとの印字を `|` で区切って書きます。
段の長さは違っていて構いません。空けたいキーは全角スペースを入れます。

```
keymap = 1234567890/|QLU,.FWRYP|EIAO-KTNSH|ZXCV;GDMJB
```

5段目を書くと、スペースキーの印字になります。同時押しを使う配列で便利です。

```
keymap = 1234567890−|あいうえお…|…|…|シフト
```

かな系で裏レイヤーがある場合は `keymap_sub` に同じ形で書きます。
キーの下段に単打、上段の小さい臙脂色に裏レイヤーが刷られます。

**作者提出の画像を使う場合**は `public/figures/` に画像を置き、`figure` にファイル名を書きます。

### 3. 動画を作る場合（任意）

打鍵列の計算は別リポジトリ **typing-distance** に任せています。
そちらに配列定義の JSON があるものだけ、動画を出せます。

1. `tools/anim_layouts.json` に対象の配列を書き足す
2. 次を実行する

```
python tools/make_animation.py --engine ../typing-distance
```

`--engine` には typing-distance のフォルダを指定します。
`public/anim/<id>.json`（動画用）と `src/data/heat.json`（ヒートマップ用）が
書き出されるので、CSV の `anim` 列に同じ id を書きます。**この1列で、動画と
ヒートマップの両方が詳細ページに出ます。**

計算結果はエンジン本体の出力と一致するか毎回検算しており、
食い違うとエラーで止まります。

### 盤面に出せるキー

typing-distance の「使えるキーID」すべてに対応しています。

| 種類 | キーID |
|---|---|
| 指キー | `1234567890-=` `qwertyuiop[]` `asdfghjkl;'` `zxcvbnm,./` |
| 親指キー | `space` `henkan` `muhenkan` `kana` `lthumb` `rthumb` |
| シフトキー | `lshift` `rshift` |

**盤面は、その配列が実際に使うキーだけを描きます。** `=` `[` `]` `'` や親指キー・
シフトキーは、配列定義に登場したときだけ現れます。使わない配列では従来どおり
数字段11＋3段の形になるので、無駄に横へ広がりません。

親指キーとシフトキーには既定の刻印（`無変換` `変換` `かな` `Shift` など）が入り、
配列側で文字を割り当てていれば、そちらが優先されます。割り当てのないキーは
薄いグレーで表示されるので、使うキーと使わないキーが見分けられます。

親指キーの打鍵は、左右どちらにも数えず「親指」として集計します。

### キーの並びについて

配列図・ヒートマップ・動画の盤面は、すべて `src/lib/keyboard.js` の同じ関数で
組み立てています。CSV の `geometry` を変えると**3つとも同時に切り替わります**ので、
図ごとに並びが食い違うことはありません。

動画では、比較用に並ぶQWERTYだけは常にロウスタッガードで描きます。

### ヒートマップについて

お題文 全10,872字を打ったときの、キーごとの打鍵回数を色の濃さで表します。
同時押しに使うキーは、その回数分だけ数えます（薙刀式のスペースキーなど）。
あわせて左手・親指・右手の打鍵比も出しています。

色は配列のジャンル色を薄めて使うので、ジャンルごとに見た目が変わります。
配色を変えたい場合は `src/data/genres.json` の `color` を書き換えてください。

## 公開する

### Cloudflare Pages につなぐ（最初の1回）

1. このフォルダを GitHub にアップロードする
2. Cloudflare にログインし、Workers & Pages → 「Pages」→「Git に接続」
3. このリポジトリを選ぶ
4. ビルド設定を次のように入力する

| 項目 | 値 |
|---|---|
| フレームワーク プリセット | Astro |
| ビルド コマンド | `npm run build` |
| 出力ディレクトリ | `dist` |

以降は `git push` するだけで、自動でビルドされて公開されます。
`main` 以外のブランチに push すると、そのブランチ専用のプレビューURLが作られます。
**公開前に見せて確認していただきたいときは、この URL を使ってください。**

独自ドメインを使う場合は `astro.config.mjs` の `site` も書き換えます。

## 正式公開前の閲覧制限

このリポジトリは**既定で非公開モード**です。次の3つが自動で効きます。

- 全ページに `noindex, nofollow, noarchive` が入り、検索エンジンに載りません
- `robots.txt` が全クローラを拒否します
- ページ上部に「この版は公開前の確認用です」という帯が出ます

**正式公開するときは**、Cloudflare Pages の 設定 → 変数とシークレット に
`PUBLIC_INDEXABLE` = `true` を追加して、再デプロイしてください。
帯が消え、検索エンジンに載るようになります。

### 制限の強さは3段階あります

| | 誰が見られるか | 設定 |
|---|---|---|
| **1. リンク限定** | URLを知っている人すべて | 既定のまま。URLを伝えた相手にだけ渡す |
| **2. パスワード** | URLとパスワードを知っている人 | `functions/_middleware.js.example` を `_middleware.js` に改名し、環境変数 `SITE_USER` `SITE_PASSWORD` を設定 |
| **3. ログイン** | 招待したメールアドレスの人だけ | Cloudflare Zero Trust の Access を設定（無料枠で50人まで） |

**1はあくまで「見つかりにくい」状態です。** URLを渡した相手が転載すれば誰でも入れます。
確認をお願いする相手が限られていて、内容が漏れても困らないならこれで十分です。

**2はブラウザの標準ダイアログでパスワードを聞く方式**で、URLと合わせて1組の合言葉を
配る形になります。作者ごとに分ける必要がない場合はこれが手軽です。

**3は誰がいつ見たかまで残せます。** Cloudflare のダッシュボードから
Zero Trust → Access → Applications で、このPagesプロジェクトを指定し、
許可するメールアドレスを登録します。相手にはワンタイムコードがメールで届きます。

### ブランチのプレビューURLを使う方法

`main` 以外のブランチに push すると、`<ブランチ名>.<プロジェクト名>.pages.dev` という
専用URLが自動で作られます。本番URLを伏せたまま特定の版だけ見せられるので、
**「この形で公開しますがよいですか」と作者の方に確認する用途に向いています。**

プレビューURLだけに制限をかけることもできます。設定 → Access ポリシー で
「プレビュー展開」のみ保護する指定が可能です。

## フォルダの中身

```
src/data/layouts.csv       配列のデータ。ふだん編集するのはここ
src/data/genres.json       ジャンルの名前・色・解説文
src/data/heat.json         ヒートマップのデータ（自動生成。手で編集しない）
src/lib/data.js            CSV の読み込みと並び替え
src/lib/keyboard.js        配列図の組み立て
src/components/            部品（配列図・カード・動画）
src/pages/index.astro      一覧ページ
src/pages/layouts/[id].astro  詳細ページ（配列の数だけ自動生成される）
public/figures/            作者提出の配列図
public/anim/               動画のデータ
src/pages/robots.txt.js    検索エンジン向けの指示
functions/                 パスワード保護（既定では無効）
tools/make_animation.py    動画データの生成
tools/seed_csv.py          ダミーデータの生成（実データが揃えば不要）
```

## いま入っているデータについて

**掲載中の10配列はすべてダミーです。** 実データに差し替えてから公開してください。

配列名・作者名・年・Q1〜Q4の文面は、design確認用に作った架空のものです。
ただし次の2点は実在のデータを使っています。

- **大西配列と DVORAK の配列図・動画** … 実際のキー配置から計算しています
- **抜刀式の動画** … 薙刀式の配列定義を仮に使っています。**抜刀式の実際の打ち方ではありません**

公開前に、`src/data/layouts.csv` と `tools/anim_layouts.json` の両方を実データに
置き換えてください。
