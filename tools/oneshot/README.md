# 薙刀式＋ワンショット漢直の動画データ

typing-distance のエンジンには漢字直接入力の仕組みがないため、この配列だけは
ここで打鍵列を作ります。

```
pip install fugashi unidic-lite pykakasi   # 最初の1回だけ
python tools/oneshot/make.py
```

`public/anim/naginata-oneshot.json` と、`src/data/heat.json` の `naginata-oneshot` の項目が
書き出されます。ほかの配列の項目には手を触れません。

## お題文の作り方

`texts/wagahai_kanji_ruby.txt`（ルビ入りの漢字まじり原文）と `texts/wagahai_hira.txt`
（他の配列と同じひらがな本文）を突き合わせて、漢字ごとの読みを取り出します。

- ワンショット漢直の表にある漢字は漢字のまま、ない漢字はひらがなに置き換えます。
- 「々」は、直前の漢字を漢直で打ったときだけ「々」として打ちます。
- 当て字の「以太利」「波斯」は、ルビどおり「イタリー」「ペルシャ」にしています。
- できあがったお題文は `texts/wagahai_oneshot.txt` に書き出されます。

ルビの切り出しを自動で誤る箇所は、`run_align.py` の `RFIX` で直しています。
漢字1字ごとの読みの分け方を誤る箇所は、`build.py` の `SPLIT_FIX` で直しています。

## 打ち方

| 対象 | 打ち方 | アクション |
|---|---|---|
| かな | 薙刀式 v18。シフト面はスペースとの同時押し、濁音・半濁音・拗音は同時押し | 1 |
| 主漢字面・単打 | 変換＋キー の同時押し | 1 |
| 主漢字面・同手／逆手 | 変換＋V（またはM）を同時押ししたあと、キーを単独で押す | 2 |
| 機能漢字面・同時1 | S＋D＋F または J＋K＋L と、逆手のキーの4キー同時押し | 1 |
| 機能漢字面・同時2 | X＋C＋V または M＋,＋. と、逆手のキーの4キー同時押し | 1 |
| 「？」「・」 | J＋K＋D、J＋K＋T の同時押し | 1 |
| 「―」 | 打鍵に含めない | 0 |

漢字の表は `kanji_table.py` にあります。

かなだけで打った場合の集計（アクション・打鍵・同時押し）は、エンジンで計算した
薙刀式の値と一致することを確認しています。

## 動画での表示

動画データの各アクションには、漢直のとき `L`（漢字面の名前）が付いています。
`TypingPlayer.astro` はこれを見て、そのアクションのあいだだけ盤面の刻印を漢字面に
差し替え、押したキーを藍色で光らせます。`L` を持たない配列の表示は変わりません。
